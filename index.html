PrOTEUM: Protein Outcomes via Tax and Elasticity User Model

Cross-elasticity for dietary proteins

This document embeds Table 6 of Dogbe et al.'s (2024) "Nutritional implications of substituting plant-based proteins for meat: evidence from home scan data" Agriculture and Food Economics 12, 30 (doi:10.1186/s40100-024-00324-8) in a way that allows you to explore the impact of percentage changes in prices on quantities, and the effect of changes in quantities on prices. Weight (which economists sometimes refer to as 'volume') data are based on Table 1 in the same paper. These are supplied per capita per week. Conversion to annual consumption assumes 365 days per year. We use a figure of 5.55 million for the population of Scotland, based on the National Records of Scotland's mid-2024 population estimates.

The caption for the table says that it contains the uncompensated elasticity of demand for animal and plant protein in Scottish households, based on the authors' computations using Kantar Worldpanel data, 2023.

Usage

To use the interactive table below, your web browser needs to have JavaScript enabled. You can then do one of the following:

  1. Enter percentage changes in the % Change Price column and click the (Update ...) ... Quantities button to see the effect on demand.
  2. Enter percentage changes in the % Change Demand column and click the (Update ...) ... Prices button to see the effect on prices.
  3. Enter percentage changes in the % Change Price column, and click the (Find ...) ... Quantities button to find the changes in demand that would lead to those changes in price, and the other consequent price changes (see below).
  4. Enter percentage changes in the % Change Demand column, and click the (Find ...) ... Prices button to find the changes in price that would lead to those changes in demand, and the other consequent demand changes (see below).

If you want, you can then save the table by clicking the button below. (Check the checkbox if you will be looking at the downloaded CSV file with Microsoft Excel.) To start again, just refresh the page.

Note that the original tables in Dogbe et al. (2024) had standard errors on each of the matrix entries that are not included as propagated uncertainties in the output numbers. However, the standard errors can be used to remove from the cross-elasticity matrix those entries that are not significant. An element of the cross-elasticity matrix is not significant if its absolute value divided by its corresponding standard error is less than 1.96. That element should then be set to zero. If you check the 'Only significant?' box, then the appropriately revised cross-elasticity matrix (or its inverse) will be used instead of that as per Table 6.

Dogbe et al.'s Scenarios

Table 5 of the Dogbe et al. paper shows four 10% tax increase scenarios. Click the corresponding button to implement that scenario in the table above.

  • On p. 17, this is found to cause lamb and mutton to decrease in demand by 17.10%, and eggs by 5.99%; while nuts, seeds and peanut butter increase in demand by 5.13%, and peas by 0.82%.
  • On p. 17, increasing red meat by 10% is observed to cause reduction in demand for poultry and pork as well.
  • On p. 18, increasing white meat by 10% leads to increases in demand for dairy of 0.58%, and for beef and veal, 0.84%. However, demand for fish decreases by 15.92%, and that for poultry by 13%. Similarly, peas see demand decreased by 2.95% in this scenario
  • On p. 18, this scenario leads to increases in demand for all proteins except those taxed (eggs and dairy).

Note that minor discrepancies between the changes in demand arising from changes in price as reported in Dogbe et al. and those in the table above, are caused by Table 6 only providing numbers to three decimal places.

More Complicated Scenarios

The cross-elasticity matrix allows us to explore slightly more complicated scenarios, which are enabled here using the 'Find...' buttons under the table. In more complicated scenarios, we are asking one of the following two questions:

  1. Suppose we want to achieve a given change in price for some subset of the protein sources. What change in demand for only those sources results in that change, and what is the effect of that change in demand on prices for the other sources?
  2. Suppose we want to achieve a given change in demand for some subset of the protein sources. What change in price for only those sources results in that change, and what is the effect of that change in price on demand for the other sources?

Example: reducing demand for red meat

To make question 1 concrete, we could ask of the second Dogbe et al. scenario: what reduction in demand for red meat leads to a price increase of 10% for those protein sources, and how does that change in demand affect the prices of other protein sources?

To explore that scenario, we set the prices for Beef and Veal; Mutton and Lamb; and Pork to 10, and the prices for all the other proteins to 0, before clicking the (Find...) ...Quantities button. You can see this by clicking the Reduce Demand for Red Meat button below:

  • Set the desired increase in price for red meat to 10%, work out the change in demand needed to bring that about, and then see what the effect is on prices for other proteins.

If you run that example (with Only significant? unchecked), you should find that we need to reduce demand for Beef and Veal by 16.215%; Mutton and Lamb by 16.475%; and Pork by 13.952%. This shift in demand results in a price increase for Diary of 1.234%; Fish 0.527%; Eggs 0.953%; Peas 2.036%; Beans and Pulses 0.751%; Nuts, Seeds, and Peanut Butter 2.751%; and Non-Dairy Milk Substitutes by 0.497%. All the plant-based proteins become more expensive, while Poultry becomes cheaper by 0.946%. You can check the Only significant? box, but then the numbers will be different.

Example: subsidising plant-based proteins

For an example of question 2 above related to the first Dogbe et al. scenario, rather than taxing animal protein, we could subsidise plant-based proteins. So, what subsidies do we need to offer for plant-based proteins to achieve, say, a 10% increase in their demand? And then, how do those price changes affect the change in demand for other proteins?

To implement that, we set the quantities for Peas; Beans and Pulses; Nuts, Seeds, and Peanut Butter; and Non-Dairy Milk Substitutes to 10, and those for all the other proteins (including Miscellaneous) to 0. Then we click the (Find ...) ...Prices button. You can see this by clicking the Subsidise Plant-Based Products button below:

  • Set the desired increase in plant-based proteins to 10%, work out the change in prices for those products needed to bring that about, and then see what the effect is on demand for animal proteins.

The results (with Only signficant? unchecked) tell us we need to reduce the price of Peas by 15.569%; Beans and Pulses by 8.067%; Nuts, Seeds, and Peanut Butter by 6.709%; and Non-Diary Milk Substitutes by 10.767%. The effects on the animal proteins are small: Mutton and Lamb increases in demand by 1.457%, Poultry by 0.519%, and Eggs by 0.134%. There are decreases in demand of less than 1% for Dairy (0.333); Beef and Veal (0.702); Pork (0.939); and Fish (0.347).

Notes

Going from quantity to price requires us to find the inverse of the matrix in Dogbe et al.'s Table 6. Earlier versions of this page hard-coded the inverse from the results of the solve() function using R. However, implementing the Find... buttons requires calculation of the inverse matrix on the fly, for which we have used the mathjs library.

The mathematics behind the Find... buttons uses block matrix algebra, shuffling around the cross-elasticity matrix so that the first \(k\) rows and columns correspond to the \(k\) elements you have set to non-zero in % Change Prices or % Change Demand. For the purposes of this explanation we will assume it is % Change Prices you have set \(k\) non-zero numbers in, and then we let \(M\) be the appropriately shuffled cross-elasticity matrix. The process for % Change Demand is the same, except that \(M\) is the appropriately shuffled inverse cross-elasticity matrix.

The normal process for calculating the change in quantity \(\Delta Q\) for a given change in price \(\Delta P\) is:

\[ M \Delta P = \Delta Q \]

But our scenario is a bit more complicated. We only know the prices of the first \(k\) elements of \(\Delta P\), and we want to find the first \(k\) elements of \(\Delta Q\), with the other \(12 - k\) elements set to 0. To get round that, we write \(M\), \(\Delta P\) and \(\Delta Q\) as block matrices, with the above equation being rewritten as:

\[ \begin{bmatrix} A & B \\ C & D \end{bmatrix} \begin{bmatrix} R \\ S \end{bmatrix} = \begin{bmatrix} T \\ U \end{bmatrix} \]

Here, matrix \(A\) is a \(k \times k\) square matrix, \(B\) is \(k \times 12 - k\), and so on. The numbers we want to find in \(\Delta Q\) is the vector \(T\) of length \(k\), and all the remaining elements \(U\) are 0. Using block matrix algebra, we know that:

\[ T = AR + BS \]

(You can satisfy yourself of this by expanding all the terms in the corresponding matrix multiplications.)

To find \(T\), we therefore need to know the values of \(S\), which have not been supplied. Using 0 to represent \(U\) (so 0 is an appropriate length vector not a scalar):

\[ 0 = CR + DS \]

Rearranging in terms of \(S\):

\[ S = D^{-1}(-CR) \]

Substituting for \(S\) in the formula for \(T\):

\[ T = AR + B(D^{-1}(-CR)) \]

And so we have found all the unknown variables we need, and the inverse matrix we need to calculate on the fly is \(D^{-1}\).

If you would like to download the above cross-elasticity matrix, its inverse, the standard errors, or the original consumption data from Dogbe et al., then the buttons below provide the means to do so. Note that if you have checked the 'Only significant?' box in the table above, then the buttons for downloading the matrix (and its inverse) will download the corrected matrix (and its inverse) rather than the values in the original paper.
